# Agent-based transmission model
The file Human-to-mosquito transmission model.R includes a within-human model used to simulate trajectories of parasitemia and male and female gametocytemia, a PK–PD model for DHA, piperaquine, and primaquine, and a probabilistic component to simulate the probability of transmission per mosquito bite. Sensitivity analyses of the primaquine dose and the probability of transmission per mosquito bite are also included in this file.

The file MDA_ACT.R includes a PK–PD model of three rounds of mass drug administration (MDA) with DHA and piperaquine.

The file Agent-based transmission model.R includes simulations of 100 MDA trajectories (ACT-only or ACT + 0.25 mg/kg primaquine) and scenarios with changing routine treatment strategies (from ACT-only to ACT + 0.25 mg/kg primaquine).
